<p>The <code>/media</code> directory is used in Linux to automatically mount removable storage devices such as USB drives, DVDs, and external hard drives. When you insert a USB or plug in a storage device, most Linux distributions will automatically create a subdirectory inside <code>/media</code> and mount the device there. </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className":""} -->
<p>This helps users access external drives easily without needing to manually set up mount points every time. </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className":""} -->
<p>For example, a USB drive may show up as <code>/media/username/USB-Drive</code>. This system keeps removable media organized and avoids cluttering other directories. Administrators and regular users alike often interact with <code>/media</code> without realizing it, especially when browsing files from a GUI file manager. </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className":""} -->
<p>Understanding <code>/media</code> is important for Linux+ candidates because it plays a big role in how Linux handles external devices in day-to-day use.</p>
