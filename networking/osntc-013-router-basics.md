# OSNTC.013: Router Basics

A router connects different IP networks and forwards packets according to destination IP addresses and routing information.

## Learning objectives

After this lesson, the learner should be able to:

- distinguish switching from routing;
- explain how a host decides whether a destination is local or remote;
- explain the role of the default gateway;
- explain directly connected, static, dynamic, and default routes at a technician level;
- explain why Ethernet frames are rebuilt at each routed Ethernet hop while the IP packet is forwarded;
- connect ARP behavior to local next-hop delivery;
- troubleshoot basic inter-network reachability using host addressing, gateway state, routing, return paths, and policy.

## Key rule

A switch primarily forwards local Ethernet frames. A router forwards IP packets between networks.
