# Open Source Semiconductor Technician Certification (OSSTC)

**Rotation key:** `semiconductor_technician`  
**Status:** active  
**Starting lesson:** `OSSTC.001`

Hands-on semiconductor technician lessons covering fab safety, ESD control, cleanroom behavior, wafer handling, vacuum systems, process tools, metrology basics, preventive maintenance, fault isolation, and production support.

Use filenames in the form `lesson-001-<topic-slug>.md`. Technician lessons emphasize safe execution, measurements, procedures, tool response, and troubleshooting before deeper device/process design theory.
