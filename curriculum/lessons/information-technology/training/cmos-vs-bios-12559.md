<p><strong><a href="https://bitcoinversus.tech/2025/01/21/bios-basic-input-output-system-overview/">BIOS (Basic Input/Output System)</a></strong> and <strong>CMOS (Complementary Metal-Oxide Semiconductor)</strong> are closely related components in PC architecture, but they serve distinct functions. <strong><a href="https://bitcoinversus.tech/2025/01/21/bios-basic-input-output-system-overview/">BIOS</a></strong> is firmware stored on a chip on the motherboard, responsible for initializing hardware during boot-up, performing <a href="https://bitcoinversus.tech/2025/03/10/post-power-on-self-test/">POST (Power-On Self-Test)</a>, and launching the operating system. </p>

<!-- wp:paragraph {"className":""} -->
<p>It also provides a configuration interface where users can set system time, enable virtualization, configure boot order, or manage CPU and fan settings. Modern systems may use <strong>UEFI</strong>, an advanced version of BIOS with more features and a graphical interface, but the term BIOS is still widely used.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className":""} -->
<p><strong>CMOS</strong>, on the other hand, refers to the <strong>battery-powered memory</strong> that stores BIOS configuration data such as system clock, hardware settings, and boot device preferences. Without CMOS, BIOS would revert to default settings every time the computer powers off. The <strong>CMOS battery</strong> (usually a CR2032 coin cell) keeps this memory alive when the system is unplugged. </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className":""} -->
<p>If the CMOS battery fails, users may experience incorrect system time, boot errors, or lost BIOS settings. For CompTIA A+ techs, understanding the distinction helps in diagnosing boot issues, BIOS reset procedures, and explaining why system time keeps resetting.</p>
