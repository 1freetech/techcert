<!-- wp:html --><p aria-label="Java code or console output example" tabindex="0" style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;margin:1.2em 0!important;border-radius:0!important;line-height:1.55!important;color:inherit!important"><span style="white-space:pre-wrap!important;display:inline!important;font:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important;font-size:0.95em!important;line-height:1.55!important;background:transparent!important;background-color:transparent!important;border:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important">int temperature = 76;

<!-- wp:heading --><h2 class="wp-block-heading">2. Choose one case with switch</h2><!-- /wp:heading -->

<!-- wp:paragraph --><p>A classic <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">switch</code> matches a selector against case labels. In the <em>colon form</em>, <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">break</code> commonly prevents execution from falling into the next case. The arrow form, standardized in modern Java, does not fall through.</p><!-- /wp:paragraph -->

<!-- wp:html --><p aria-label="Java code or console output example" tabindex="0" style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;margin:1.2em 0!important;border-radius:0!important;line-height:1.55!important;color:inherit!important"><span style="white-space:pre-wrap!important;display:inline!important;font:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important;font-size:0.95em!important;line-height:1.55!important;background:transparent!important;background-color:transparent!important;border:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important">String mode = "maintenance";
switch (mode) {
    case "run":
        System.out.println("mode: production");
        break;
    case "maintenance":
        System.out.println("mode: service");
        break;
    default:
        System.out.println("mode: unknown");
}</span></p><!-- /wp:html -->

<!-- wp:paragraph --><p>In Java 14 and later, arrow labels can make the same selection easier to read. Each arrow case handles one selected alternative without a trailing <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">break</code>.</p><!-- /wp:paragraph -->

<!-- wp:html --><p aria-label="Java code or console output example" tabindex="0" style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;margin:1.2em 0!important;border-radius:0!important;line-height:1.55!important;color:inherit!important"><span style="white-space:pre-wrap!important;display:inline!important;font:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important;font-size:0.95em!important;line-height:1.55!important;background:transparent!important;background-color:transparent!important;border:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important">switch (mode) {

A <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">switch</code> may also be an expression that returns a value. The <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">do-while</code> condition ends with a semicolon.</p><!-- /wp:paragraph -->

<!-- wp:html --><p aria-label="Java code or console output example" tabindex="0" style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;margin:1.2em 0!important;border-radius:0!important;line-height:1.55!important;color:inherit!important"><span style="white-space:pre-wrap!important;display:inline!important;font:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important;font-size:0.95em!important;line-height:1.55!important;background:transparent!important;background-color:transparent!important;border:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important">for (int i = 0; i &lt; 3; i++) {

<!-- wp:heading --><h2 class="wp-block-heading">4. Enhanced for, continue, and break</h2><!-- /wp:heading -->

<!-- wp:paragraph --><p>An enhanced <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">for</code> loops over each value in an array or other iterable structure. It is concise when you need the value but not its numeric index. For arrays of primitive numbers, the iteration variable contains a copy of each element.</p><!-- /wp:paragraph -->

<!-- wp:html --><p aria-label="Java code or console output example" tabindex="0" style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;margin:1.2em 0!important;border-radius:0!important;line-height:1.55!important;color:inherit!important"><span style="white-space:pre-wrap!important;display:inline!important;font:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important;font-size:0.95em!important;line-height:1.55!important;background:transparent!important;background-color:transparent!important;border:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important">int[] readings = {40, 76, 92, 55};
for (int value : readings) {
    System.out.println(value);
}</span></p><!-- /wp:html -->

<!-- wp:paragraph --><p>Use an indexed loop if you need both the reading and its position. <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">continue</code> skips the remaining statements in the current iteration. <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">break</code> exits the innermost enclosing loop or switch.</p><!-- /wp:paragraph -->

<!-- wp:html --><p aria-label="Java code or console output example" tabindex="0" style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;margin:1.2em 0!important;border-radius:0!important;line-height:1.55!important;color:inherit!important"><span style="white-space:pre-wrap!important;display:inline!important;font:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important;font-size:0.95em!important;line-height:1.55!important;background:transparent!important;background-color:transparent!important;border:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important">int[] readings = {40, 76, 92, 55};
for (int i = 0; i &lt; readings.length; i++) {
    int value = readings[i];
    if (value &lt; 70) continue;
    System.out.printf("sample %d: %d C%n", i, value);
    if (value &gt;= 90) {
        System.out.println("STOP at critical sample");
        break;
    }

<!-- wp:list --><ul class="wp-block-list"><li><strong>Missing parentheses:</strong> Java uses <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">if (condition)</code>, not <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">if condition</code>.</li><li><strong>Accidental switch fallthrough:</strong> colon cases may need <code style="background:transparent!important;background-color:transparent!important;border:0!important;border-width:0!important;box-shadow:none!important;padding:0!important;border-radius:0!important;color:inherit!important;font-family:ui-monospace,SFMono-Regular,Consolas,monospace!important">break</code>; arrow cases do not implicitly fall through.</li><li><strong>Off-by-one bounds:</strong> a four-item array has indices 0–3.
