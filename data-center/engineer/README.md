# Open Source Data Center Engineer Certification (OSDCEC)

**Rotation key:** `data_center_engineer`  
**Status:** active  
**Starting lesson:** `OSDCEC.001`  
**Current next lesson:** `OSDCEC.012`

Engineering-level data-center lessons covering capacity planning, electrical one-lines, redundancy, UPS/generator systems, cooling design, airflow, network architecture, telemetry, availability, commissioning, failure domains, and efficiency.

Engineer lessons focus on one bounded architecture or calculation topic at a time, with a long-range curriculum of up to 999 lessons. Complex lessons include an elementary overview and elementary conclusion while retaining full engineering terminology and calculations.
