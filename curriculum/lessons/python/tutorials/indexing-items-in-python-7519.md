<p style="text-transform:none">The code snippet provided shows how to insert an item into a list at a specific position rather than appending it at the end.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"style":{"typography":{"textTransform":"none"}}} -->
<p style="text-transform:none"><br>Instead of adding <code>"sunglasses"</code> to the end of the list using <code>append()</code>, the task is to insert <code>"sunglasses"</code> at index <code>2</code> of the list <code>travel_items</code>.</p>
<!-- /wp:paragraph -->

<!-- wp:list {"ordered":true} -->
<ol class="wp-block-list"></ol>
<!-- /wp:list -->

<p style="font-size:1rem;text-transform:none"><strong>Explanation of the code:<br><code>travel_items.insert(2, 'sunglasses')</code></strong></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"style":{"typography":{"textTransform":"none"}}} -->
<p style="text-transform:none">This uses the <code>insert()</code> method to add <code>"sunglasses"</code> at position <code>2</code>. Index <code>2</code> refers to the third position in the list (since lists are zero-indexed). </p>
