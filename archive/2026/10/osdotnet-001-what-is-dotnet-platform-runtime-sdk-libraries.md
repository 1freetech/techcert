<!-- wp:paragraph --><p><strong>.NET is a free, open-source software development platform, not a programming language.</strong> It combines languages, a runtime, reusable libraries and developer tools. Think of it as a workshop: the language describes what to make, the SDK builds it, and the runtime runs it.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Four Parts of .NET</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>Languages such as C#, F# and Visual Basic describe instructions. The software development kit (SDK) provides compilers and tools. Libraries provide reusable features such as files, networking and collections. The runtime executes managed code and provides services including memory management. These parts work together, but are not interchangeable. Read the <a href='https://learn.microsoft.com/en-us/dotnet/core/introduction'>official .NET introduction</a>.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">Runtime Versus SDK</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>A runtime-only installation can execute compatible existing applications. To create, compile, test and publish new projects, developers generally install the <a href='https://learn.microsoft.com/en-us/dotnet/core/sdk'>.NET SDK</a>. The SDK includes runtime components. The distinction is like having a music player versus the tools for recording music.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">What Can You Build?</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>Modern .NET supports command-line tools, desktop applications, websites, background services and <a href='https://bitcoinversus.tech/2026/10/08/it-what-is-an-api-application-programming-interface/'>web APIs</a>. ASP.NET Core is a framework for web applications and services. .NET runs on Windows, Linux and macOS, although specific application frameworks have their own operating-system requirements. C# is a language commonly used with .NET, not another name for the platform. See the <a href='https://bitcoinversus.tech/2026/09/30/assembly-to-kotlin-programming-languages-changed-computing/'>history of programming languages</a>.</p><!-- /wp:paragraph -->
