OSEmojicode.004 explains how programs repeat instructions. In Emojicode 1.0 beta 2, 🔂 iterates over a range or collection, while 🔁 repeats instructions as long as a condition remains true. The approach saves programmers from manually repeating identical statements. A loop repeats a block

Emojicode encloses executable blocks between 🍇 and 🍉. A loop repeats a block rather than duplicating its individual lines in source code. The official Control Flow reference defines 🔂 as for-in, fetching values from an iterable one by one. The 🔁 construct is repeat-while, evaluating a Boolean condition before each pass. If the condition starts false, the body is skipped.

The choice depends on the task. Prefer a collection or range when a bounded group of items is already available. Use a condition-driven loop when progress depends on changing state. Either approach requires a clear stopping rule and, in real applications, appropriate resource limits.

Count with 🔂 and a numeric range

An Emojicode ⏩ range holds an immutable sequence of integers. The start value is included, while the stopping value is excluded when the step is positive. Save the following complete practice program as laps.emojic. The 🏁 symbol declares the entry point, and the inner block prints each value provided by the range.

🏁 🍇
  🔂 lap 🆕⏩ 1 6❗️ 🍇
    😀 🔡 lap❗️❗️
  🍉
🍉

The sequence is 1, 2, 3, 4 and 5. Each integer is converted into text using 🔡 lap❗️ before printing. Expected output: five lines containing 1 through 5. The expectation was derived from the language specification, not from a completed compiler run.

A third numeric argument controls the step. For example, 🆕⏩ 0 10 2❗️ produces 0, 2, 4, 6 and 8. A negative step supports descending sequences, with the reference defining a corresponding strict stopping boundary. Learners who understand half-open intervals avoid an important source of off-by-one errors.

Visit each item in a list

A 🔂 loop can traverse a list without an explicit numeric index. Emojicode's collection literal begins with 🍿 and ends with 🍆. The following program stores three device names, then prints the items in the sequence supplied by the collection.

🏁 🍇
  🍿🔤router🔤 🔤switch🔤 🔤server🔤🍆 ➡️ devices

  🔂 device devices 🍇
    😀 device❗️
  🍉
🍉

The loop variable device receives each string, giving three predicted lines: router, switch and server. The underlying idea is familiar across programming languages. OSGo.006 on arrays and slices offers a related comparison for learners working with indexed collections.

Repeat only while a condition is true

The 🔁 instruction accepts a Boolean condition rather than a collection. For a predictable demonstration, declare a mutable counter, print its current value and increment it each time. The official Variables and Assignment guide establishes 🖍🆕 for mutable declaration and ⬅️➕ for addition followed by assignment.

🏁 🍇
  0 ➡️ 🖍🆕counter
  🔁 counter ◀️ 3 🍇
    😀 🔡 counter❗️❗️
    counter ⬅️➕ 1
  🍉
🍉

The initial value is zero. The comparison counter ◀️ 3 stays true for 0, 1 and 2. Once the counter becomes 3, the next test is false, ending the loop. Expected output: 0, 1 and 2, on separate lines. Removing the increment would leave the condition true and produce an unbounded stream of zeroes until the program is interrupted. Zero-iteration cases are also important: changing the comparison limit to zero would skip the loop entirely.

Compile and check actual output

Install the 1.0 beta 2 compiler and a supported C++ compiler and linker according to the Emojicode installation guide. Use a UTF-8 text editor and save one complete sample per file.
