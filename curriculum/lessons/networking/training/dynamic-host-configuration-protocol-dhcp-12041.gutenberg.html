The Dynamic Host Configuration Protocol (DHCP) is a network service used to automatically assign IP addresses and other configuration information—such as the subnet mask, default gateway, and DNS servers—to client devices on a network.

This removes the need for manual IP configuration and helps avoid conflicts caused by duplicate IPs. DHCP is essential for managing medium to large-scale networks, as it significantly reduces administrative overhead. It operates on a client-server model and uses UDP port 67 (server) and UDP port 68 (client) to facilitate communication between the client requesting an IP and the DHCP server that provides it.

The DHCP process follows a four-step sequence known as DORA:

  • Discover – the client broadcasts a message to locate available DHCP servers.
  • Offer – the DHCP server responds with an IP address offer and configuration details.
  • Request – the client requests to accept the offered IP address.
  • Acknowledge – the DHCP server confirms the lease and the client is configured.

A typical DHCP lease is temporary, and the client must periodically renew it before expiration. DHCP servers can also reserve specific IPs for certain MAC addresses, ensuring that critical devices always receive the same IP address without static configuration—this is known as a DHCP reservation.

In troubleshooting, common DHCP-related issues include the assignment of APIPA addresses (169.254.x.x) when the client fails to contact a DHCP server, misconfigured scopes, and conflicts with manually assigned IPs.

Understanding DHCP is essential for both wired and wireless network support, and for diagnosing IP addressing problems quickly and accurately.
