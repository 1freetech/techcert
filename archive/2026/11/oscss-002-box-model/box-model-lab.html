OSCSS.002 — The CSS Box Model

Compare two boxes with different box-sizing rules. The displayed dimensions are calculated examples; inspect the elements in browser Developer Tools to see the actual rendered sizes.

content-box

width: 240px; height: 96px; padding: 20px; border: 4px;

The width applies to the content. Padding and borders increase the outside size.

Expected border-edge size: 288 × 144 px.

border-box

width: 240px; height: 144px; padding: 20px; border: 4px;

The declared width includes padding and borders. The content width is 192 px.

Expected border-edge size: 240 × 144 px.

Adjacent vertical margins

In normal block flow, a 24 px bottom margin and 12 px top margin on adjacent blocks collapse to a 24 px gap, not 36 px.
