# AxeOS Fundamentals: Read Bitaxe Telemetry Before You Tune

This second AxeOS fundamentals guide focuses on interpreting Bitaxe telemetry before making operating changes.

## Core telemetry covered

- Current, 1-minute, 10-minute and 1-hour hashrate
- Expected hashrate and hash-error percentage
- Configured versus actual ASIC frequency
- Configured versus measured core voltage
- ASIC and voltage-regulator temperatures
- Fan behavior and target temperature
- Power and current
- Accepted, rejected and pending shares
- Pool response and fallback-pool state
- Wi-Fi signal and connectivity
