<!-- wp:heading --><h2 class="wp-block-heading">Elementary Overview</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>A fiber link does not send whole files as one giant flash of light. It sends a rapid sequence of <strong>symbols</strong>. A simple signaling method called <strong>NRZ</strong> uses two levels, so each symbol can represent one bit. <strong>PAM4</strong> uses four levels, so one symbol can represent two bits. That lets an optical link carry more data without doubling its symbol rate, but the four levels sit closer together and are therefore harder for the receiver to distinguish when noise, loss, reflections, or <a href="https://bitcoinversus.tech/2026/10/04/osfoec-002-fiber-dispersion-engineering-modal-chromatic-pmd-pulse-broadening-reach-limits/">dispersion</a> distort the signal. This lesson follows <a href="https://bitcoinversus.tech/2026/10/05/osfoec-003-optical-transceiver-selection-engineering-form-factor-data-rate-fiber-type-wavelength-reach-interoperability/">OSFOEC.003 optical transceiver selection</a> by explaining what the transceiver is actually encoding onto the optical channel.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">NRZ Uses Two Levels; PAM4 Uses Four</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p><strong>NRZ</strong>, or non-return-to-zero signaling, normally represents binary 0 and 1 with two amplitude levels. <strong>PAM4</strong>, or four-level pulse-amplitude modulation, represents four amplitude states and therefore carries <strong>log₂(4)=2 bits per symbol</strong>. A 53.125 GBd PAM4 lane can therefore carry roughly 106.25 Gb/s of raw information before coding overhead, while a 53.125 GBd NRZ lane carries roughly 53.125 Gb/s. PAM4 is one reason modern 100G-per-lane, 400G, and 800G optical interfaces can increase throughput without requiring the analog front end to run at twice the baud rate. The price is reduced vertical separation between decision levels, which lowers noise margin and makes transmitter linearity, receiver sensitivity, equalization, and channel quality more important.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Symbol Rate Is Not the Same as Bit Rate</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p><strong>Baud rate</strong> measures symbols per second, while <strong>bit rate</strong> measures information bits per second. For an uncoded modulation with M possible symbol states, the ideal relationship is <strong>bit rate = symbol rate × log₂(M)</strong>. NRZ has M=2; PAM4 has M=4. Real Ethernet optics also include coding and <strong>forward error correction</strong> overhead, so line rate, payload rate, lane rate, and baud rate should not be treated as interchangeable numbers. Engineers use this distinction when selecting <a href="https://bitcoinversus.tech/2026/10/05/osfoec-003-optical-transceiver-selection-engineering-form-factor-data-rate-fiber-type-wavelength-reach-interoperability/">optical transceivers</a>, checking SerDes compatibility, estimating bandwidth requirements, and determining whether a given optical lane architecture can support the target Ethernet rate.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Eye Diagrams Show Timing and Amplitude Margin</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>An <strong>eye diagram</strong> overlays many symbol intervals so engineers can see the statistical opening available to a receiver. NRZ produces one principal eye opening; PAM4 produces three stacked eyes because four voltage or optical-power levels create three decision thresholds. A wider horizontal opening generally means more timing margin, while a larger vertical opening means more amplitude margin. Eye closure can come from bandwidth loss, jitter, noise, reflections, inter-symbol interference, dispersion, poor equalization, or transmitter defects. In optical PAM4 standards, engineers often use measurements such as TDECQ in addition to the visual eye because a pretty picture alone does not prove standards compliance.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">BER Turns Signal Quality Into a Reliability Number</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p><strong>Bit error rate (BER)</strong> is the number of incorrectly received bits divided by the total number of transmitted bits. A BER of 10<sup>−6</sup> means roughly one errored bit per million bits; high-speed optical systems often need much lower post-FEC error rates. Engineers distinguish <strong>pre-FEC BER</strong>, measured before the error-correction decoder, from <strong>post-FEC BER</strong>, measured after correction. Pre-FEC BER reveals how hard the physical channel is working, while post-FEC BER tells whether the delivered data meets the required reliability target. Optical receive power from <a href="https://bitcoinversus.tech/2026/10/04/osfotc-002-optical-power-meter-basics-dbm-wavelength-reference-levels-receive-power/">power-meter testing</a> is important, but two links with similar received power can have different BER if dispersion, reflections, noise, or transmitter quality differ.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">FEC Trades Redundancy for a Lower Delivered Error Rate</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p><strong>Forward error correction (FEC)</strong> adds structured redundant information so the receiver can detect and correct a limited number of errors without requesting retransmission. This is especially valuable in high-speed Ethernet optics because PAM4 operates with smaller level spacing than NRZ and can tolerate a higher raw error rate when a specified FEC scheme is part of the interface. FEC is not free: parity symbols consume bandwidth, decoding adds latency and power, and every code has a correction limit. If pre-FEC BER rises beyond the code’s capability, post-FEC performance can collapse quickly. Engineers therefore treat FEC as part of the link architecture rather than as permission to ignore poor optical margin or bad <a href="https://bitcoinversus.tech/2026/10/06/osfotc-004-fiber-connector-types-polarity-lc-sc-upc-apc-mpo-mtp-tx-rx-vfl-verification/">fiber connections and polarity</a>.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">PAM4 Is a System-Level Tradeoff, Not Automatically Better Signaling</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>PAM4 improves spectral efficiency by carrying two bits per symbol, but it also makes the signal more sensitive to noise and nonlinearity. NRZ can still be preferable where the required lane rate, reach, power, and cost do not justify four-level signaling. Modern optical modules combine high-speed <strong>SerDes</strong>, modulators, photodetectors, DSP, FEC, clock recovery, packaging, and increasingly <a href="https://bitcoinversus.tech/2026/09/24/globalfoundries-marvell-ai-optical-networking-chip-capacity/">advanced semiconductor and optical integration</a>. That system-level view is important: higher efficiency often comes from putting the right semiconductor, photonic, packaging, and coding technologies together rather than demanding that one device or material perform every function. The same idea appears in single-wavelength 100G optics and in the broader move toward silicon photonics and heterogeneous integration.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Worked Example: 100 Gb/s Raw Lane Target</h2><!-- /wp:heading -->
<!-- wp:list --><ul class="wp-block-list"><li><strong>NRZ:</strong> 1 bit/symbol, so approximately 100 GBd would be required for 100 Gb/s before coding overhead.</li><li><strong>PAM4:</strong> 2 bits/symbol, so approximately 50 GBd would carry 100 Gb/s before coding overhead.</li><li><strong>Engineering benefit:</strong> the required symbol rate is roughly halved.</li><li><strong>Engineering cost:</strong> four amplitude levels reduce vertical decision margin and increase sensitivity to noise and distortion.</li><li><strong>System response:</strong> stronger transmitter/receiver linearity, equalization, measurement, and FEC are used to recover reliable data.</li></ul><!-- /wp:list -->

<!-- wp:heading --><h2 class="wp-block-heading">Engineering Checklist</h2><!-- /wp:heading -->
<!-- wp:list {"ordered":true} --><ol class="wp-block-list"><li>Identify the required payload rate, line rate, lane count, and symbol rate.</li><li>Confirm whether each electrical and optical lane uses NRZ, PAM4, or another modulation.</li><li>Calculate bits per symbol using log₂(M).</li><li>Verify transceiver, host SerDes, fiber type, wavelength, and reach compatibility.</li><li>Check link budget and dispersion margin from OSFOEC.001 and OSFOEC.002.</li><li>Inspect the eye or standards-defined transmitter metric.</li><li>Measure pre-FEC BER under realistic temperature and channel conditions.</li><li>Confirm the required FEC mode on both ends of the link.</li><li>Verify post-FEC performance and monitor corrected/uncorrectable codeword counters.</li><li>Do not accept a link solely because received optical power is inside the nominal range.</li></ol><!-- /wp:list -->

<!-- wp:heading --><h2 class="wp-block-heading">Knowledge Check + Answers</h2><!-- /wp:heading -->
<!-- wp:list {"ordered":true} --><ol class="wp-block-list"><li><strong>How many bits does one PAM4 symbol represent?</strong> Two bits.</li><li><strong>What is baud?</strong> Symbols per second.</li><li><strong>Why does PAM4 have three eyes?</strong> Four amplitude levels create three decision boundaries.</li><li><strong>What does BER measure?</strong> The fraction of received bits that are incorrect.</li><li><strong>What is pre-FEC BER?</strong> The raw error rate before the FEC decoder corrects errors.</li><li><strong>What does FEC add to the transmission?</strong> Structured redundancy that lets the receiver detect and correct a limited number of errors.</li><li><strong>Does acceptable received optical power guarantee a good link?</strong> No. Dispersion, noise, reflections, modulation quality, and other impairments can still produce excessive BER.</li></ol><!-- /wp:list -->

<!-- wp:heading --><h2 class="wp-block-heading">Elementary Conclusion</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>NRZ is like sending information with a light that has only two clearly different choices. PAM4 uses four choices, so each signal can carry twice as many bits, but the choices are closer together and easier to confuse. Engineers use eye diagrams to see whether those choices are still separated, BER to count how often the receiver guesses wrong, and FEC to repair a limited number of those mistakes. The useful lesson is that faster fiber is not created by one trick. Modern links combine better modulation, better optics, better semiconductors, better signal processing, and better error correction so more information can move through the same physical channel without losing reliability.</p><!-- /wp:paragraph -->
