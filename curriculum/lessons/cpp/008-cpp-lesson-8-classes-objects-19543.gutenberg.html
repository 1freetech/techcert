A C++ class is a way to describe a kind of thing in a program. An object is one actual thing created from that class. Think of a class as a character template in a game and an object as one character made from that template.

A Simple Gaming Example

#include <iostream>
#include <string>

class Player {
public:
    std::string name;
    int health;
};

int main() {
    Player hero;
    hero.name = "Alex";
    hero.health = 100;

    std::cout << hero.name << " has "
              << hero.health << " health.\n";

    return 0;
}

Player is the class. hero is an object created from that class. The object has a name and health value because those pieces of data are members of Player.

Class vs. Object

  • Class: the definition or template.
  • Object: an instance created from that class.
  • Member: data or behavior that belongs to the class.

Bitcoin Mining Example

class Miner {
public:
    std::string model;
    int hashrate;
};

Miner machine;
machine.model = "Miner A";
machine.hashrate = 200;

Here, Miner describes a simple type of mining machine. machine is one object. Keeping the example small makes the new idea clear: related information can be grouped into a class.

Sports Example

class Team {
public:
    std::string name;
    int score;
};

Team home;
home.name = "Home";
home.score = 21;

The same pattern works for a sports team, game character, Bitcoin miner, car, song, or almost anything else a program needs to represent.

Why Classes Matter

Classes let programmers create their own types and keep related information together. Later lessons can add member functions, constructors, private data, and other object-oriented programming features. For now, focus only on the relationship: class defines the type; object is an instance of that type.

Practice

  1. Create a class named Game.
  2. Add a string named title.
  3. Add an integer named score.
  4. Create one Game object.
  5. Give the object a title and score, then print them.

Key Takeaway

A class defines a program-created type. An object is an instance of that type. This gives C++ programs a simple way to represent familiar things while keeping related data together.
