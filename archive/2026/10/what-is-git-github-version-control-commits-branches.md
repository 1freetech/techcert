<!-- wp:paragraph --><p><strong>Git is a version-control system that remembers how files change over time. GitHub is an online service where people host Git repositories and collaborate.</strong> Together, they make it easier to experiment, recover older work, review changes and share software. You do not need to be a professional programmer to benefit: Git can track documentation, website files, lesson drafts and configuration files too.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">Git and GitHub Are Not the Same Thing</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>Git runs locally on your computer. You can create commits, inspect history and work on branches without a GitHub account or an internet connection. GitHub adds remote hosting, issue tracking, pull requests, access controls and automation. Git can also work with other hosting services or private servers. This distinction matters for <a href='https://bitcoinversus.tech/2026/10/08/what-is-open-source-software-sharing-code-build-better-technology/'>open-source software</a>: putting files on GitHub does not automatically grant an open-source license.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">What Is a Repository?</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>A repository, often shortened to <em>repo</em>, is a project directory whose history Git tracks. Its hidden <code>.git</code> directory contains metadata and version history. A commit is a recorded snapshot of changes with a message describing what changed. A branch is a movable pointer to a sequence of commits, allowing developers to try new work without immediately changing the main branch.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">Your First Git Project</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>After installing Git from <a href='https://git-scm.com/downloads'>the official downloads page</a>, open a terminal and try these commands in a new folder. Set your name and email once before committing; use an email address you are comfortable associating with commits.</p><!-- /wp:paragraph -->
<!-- wp:code --><pre class="wp-block-code"><code>mkdir my-first-project
cd my-first-project
git init
git config user.name "Your Name"
git config user.email "you@example.com"
echo "# My First Project" &gt; README.md
git add README.md
git commit -m "Add project README"
git status</code></pre><!-- /wp:code -->
<!-- wp:heading --><h2 class="wp-block-heading">What Each Command Does</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p><code>git init</code> starts a repository. <code>git add</code> stages selected changes for the next commit. <code>git commit</code> records the staged snapshot. <code>git status</code> tells you which files changed and whether anything remains to commit. Git does not automatically upload your work to the internet: pushing to a remote repository is a separate operation.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">Branches and Pull Requests</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>Imagine editing a tutorial while someone else fixes a typo. Separate branches let both changes proceed independently. A GitHub pull request proposes merging one branch into another and provides a place for discussion, code review and automated checks. A reviewer can request improvements before the changes reach the default branch. This workflow is useful for <a href='https://bitcoinversus.tech/2026/10/08/what-is-raspberry-pi-tiny-computer-linux-coding-electronics/'>Raspberry Pi</a> projects, documentation and large applications alike.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">What Should You Put in a Git Repository?</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>Good candidates include source code, text-based documentation, configuration templates, tests and project instructions. Avoid committing passwords, API keys, private customer data, huge generated files or machine-specific secrets. Use a <code>.gitignore</code> file for local build outputs and temporary files. If a secret is accidentally committed, removing it from the latest version is not enough: treat the secret as compromised and rotate it.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">Does a Public GitHub Repo Mean Open Source?</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>No. Public visibility allows people to read files, but reuse rights depend on licensing. An educational project might license original lessons under Creative Commons BY-SA 4.0, while accompanying software uses a suitable software license such as MIT or Apache 2.0. Third-party photos and videos remain governed by their own permissions. See our <a href='https://bitcoinversus.tech/2026/10/08/what-is-open-source-software-sharing-code-build-better-technology/'>open-source software overview</a> for the distinction.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">Five Things to Learn Next</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>Once you are comfortable committing files, practice reading <code>git log</code>, comparing edits with <code>git diff</code>, creating a branch with <code>git switch -c feature-name</code>, connecting a remote with <code>git remote add origin URL</code>, and pushing with <code>git push -u origin feature-name</code>. Use a test repository until you understand how branches and remotes work. For command-line fundamentals, also see our guide to the <a href='https://bitcoinversus.tech/2026/10/08/it-what-is-path-environment-variable-windows-linux/'>PATH environment variable</a>.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">Why It Matters</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>Version control gives you a history you can inspect instead of relying on filenames like <code>final-v2-really-final</code>. It also makes collaboration more accountable: contributors can see which change introduced a feature or bug, discuss it and correct it. That makes Git useful for software development, technical documentation, training materials and long-running community projects.</p><!-- /wp:paragraph -->
