<p>An <strong><a href="https://bitcoinversus.tech/2025/04/10/static-ip-vs-dhcp/">IP address</a></strong> is a unique identifier assigned to devices on a network to enable communication. There are two main versions: <strong><a href="https://bitcoinversus.tech/2025/04/25/ipv4-vs-ipv6/">IPv4</a></strong>, a 32-bit address format (e.g., 192.168.1.1), and <strong><a href="https://bitcoinversus.tech/2025/03/30/ipv6/">IPv6</a></strong>, a 128-bit format (e.g., 2001:0db8:85a3::8a2e:0370:7334), created to handle the growing number of connected devices.</p>

<!-- wp:paragraph {"className":""} -->
<p><strong>IPv4</strong> supports around 4.3 billion addresses and uses <strong>dot-decimal notation</strong>. It’s still widely used in LANs, home networks, and small office setups. </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className":""} -->
<p><strong>IPv6</strong> uses <strong>hexadecimal and colons</strong>, offering a virtually unlimited pool of addresses and built-in features like simplified routing and better security through IPsec.</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3,"className":""} -->
<h3 class="wp-block-heading">Why It Matters for Technicians</h3>
<!-- /wp:heading -->

<!-- wp:paragraph {"className":""} -->
<p>A+ techs must understand how IP addresses are <strong>assigned manually (static)</strong> or <strong>automatically via DHCP</strong>, and how <strong>subnetting</strong> works to divide networks. Troubleshooting often includes verifying IP configurations using commands like <code>ipconfig</code> (Windows) or <code>ifconfig/ip a</code> (Linux).</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className":""} -->
<p>Knowing how to read IP addresses, determine subnet masks, and identify default gateways helps isolate issues with DNS, routing, and connectivity. It also enables better management of printers, routers, and networked devices across both IPv4 and IPv6 environments.</p>
