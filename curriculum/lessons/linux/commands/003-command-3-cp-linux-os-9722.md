<!-- wp:paragraph {"style":{"typography":{"textTransform":"none"}}} -->
<p style="text-transform:none">The <code>cp</code> command in Linux is used to copy files and directories. </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"style":{"typography":{"textTransform":"none"}}} -->
<p style="text-transform:none">It's a powerful utility that can create copies of data from one location to another, either within the same directory or across different directories.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"id":9724,"sizeSlug":"large","linkDestination":"none"} -->
<figure class="wp-block-image size-large"><img src="https://bitcoinversus.tech/wp-content/uploads/2024/11/cp-linux-comand.png?w=958" alt="" class="wp-image-9724" /></figure>
<!-- /wp:image -->

<!-- wp:paragraph {"style":{"typography":{"textTransform":"none"}}} -->
<p style="text-transform:none">Adding the <code>-r</code> (recursive) flag allows you to copy entire directories, including their contents.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"style":{"typography":{"textTransform":"none"}}} -->
<p style="text-transform:none">This command copies the <code>newfile</code> directory and all its contents into a new directory called <code>clone</code>. The <code>-r</code> flag ensures that all subdirectories and files inside <code>newfile</code> are copied as well.</p>
<!-- /wp:paragraph -->
