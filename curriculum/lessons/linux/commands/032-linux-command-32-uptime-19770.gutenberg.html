The Linux uptime command gives you a quick answer to a basic technician question: how long has this computer been running? It also shows how many users are signed in and a short view of system load.

This follows Linux Command #31 – stat (Linux OS).

Run the Command

uptime

A computer might respond with something like:

10:24:17 up 3 days, 4:26, 2 users, load average: 0.18, 0.24, 0.20

Read the Output

  • 10:24:17 — the current system time.
  • up 3 days, 4:26 — how long the machine has been running since its last boot.
  • 2 users — the number of logged-in user sessions.
  • load average — three numbers summarizing recent system workload over approximately 1, 5, and 15 minutes.

For this beginner lesson, remember that load average is a quick workload indicator. We will interpret CPU and process performance in more detail in later lessons.

Make It Easier to Read

uptime -p

The -p option means pretty. It returns a simpler result such as:

up 3 days, 4 hours, 26 minutes

See When the Computer Started

uptime -s

The -s option shows the date and time when the system started.

Data Center Example

A server unexpectedly stops responding and comes back online. A technician can run uptime. If the result says the server has only been up for a few minutes, that is a quick clue that it recently rebooted.

Bitcoin Mining Example

If a Linux management computer at a mining site was expected to run continuously, uptime can quickly show whether that computer recently restarted before you investigate applications, networking, or connected miners.

Practice

  1. Open a Linux terminal.
  2. Run uptime.
  3. Identify how long the machine has been running.
  4. Run uptime -p.
  5. Run uptime -s and identify the system start time.

Key Takeaway

uptime is a fast first-check command. It tells a technician how long Linux has been running, how many user sessions are active, and the recent system load.
