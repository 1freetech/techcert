<!-- wp:heading --><h2 class="wp-block-heading">Elementary Overview</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>A fiber link can fail even when the cable is unbroken and the connectors appear normal. Dust, oil, scratched end faces, poor reference setup, wrong wavelength, dirty test cords, and excessive connector or splice loss can all reduce received optical power. A technician therefore follows a repeatable sequence: <a href="https://bitcoinversus.tech/2026/10/04/osfotc-001-fiber-optic-safety-handling-inspection-cleaning-basics/">inspect and clean</a>, establish a reference, measure the link, compare the result with the allowed loss, record the evidence, and troubleshoot only when the measurement is trustworthy. This lesson turns the individual skills from <a href="https://bitcoinversus.tech/2026/10/04/osfotc-002-optical-power-meter-basics-dbm-wavelength-reference-levels-receive-power/">OSFOTC.002 optical power-meter basics</a>, <a href="https://bitcoinversus.tech/2026/10/05/osfotc-003-otdr-field-testing-launch-receive-fibers-range-pulse-width-events-dead-zones-fault-location/">OSFOTC.003 OTDR testing</a>, and <a href="https://bitcoinversus.tech/2026/10/06/osfotc-004-fiber-connector-types-polarity-lc-sc-upc-apc-mpo-mtp-tx-rx-vfl-verification/">OSFOTC.004 connector and polarity verification</a> into one field workflow.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Inspect And Clean Before You Reference</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>The test set is only as trustworthy as the interfaces connecting it to the fiber. Inspect the connector end face with an appropriate fiber inspection scope, clean when contamination is present, and inspect again before mating. Never look directly into an active fiber with an optical microscope, and follow the safety method established in <a href="https://bitcoinversus.tech/2026/10/04/osfotc-001-fiber-optic-safety-handling-inspection-cleaning-basics/">OSFOTC.001</a>. Clean both the link connector and the reference test cords, protect unused adapters with caps, and avoid touching ferrule end faces. If a reference cord is dirty while the zero reference is established, every later result can inherit that error.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Set The Reference Before Measuring Link Loss</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>An <a href="https://bitcoinversus.tech/2025/12/10/olts-optical-loss-test-set/">optical loss test set</a> combines a stabilized light source with an <a href="https://bitcoinversus.tech/2026/10/04/osfotc-002-optical-power-meter-basics-dbm-wavelength-reference-levels-receive-power/">optical power meter</a>. First select the wavelength required for the fiber and test plan, connect known-good reference cords using the required reference method, and store the reference value. The link loss is then the difference between the reference power and measured power: <strong>Loss (dB) = Reference Power (dBm) − Measured Power (dBm)</strong>. If the stored reference is −2.0 dBm and the far-end measurement is −4.3 dBm, the measured insertion loss is <strong>2.3 dB</strong>. The reference method must remain consistent because adding or removing test-cord connections changes what the measurement includes.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Measure, Compare, Record, Then Troubleshoot</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>After the reference is established, connect the fiber under test without disturbing the reference connection that the procedure requires you to keep fixed. Measure at the specified wavelength or wavelengths, record the measured loss, and compare it with the project acceptance limit or calculated <a href="https://bitcoinversus.tech/2026/10/04/osfoec-001-optical-link-budget-engineering-db-power-loss-design-margin/">loss budget</a>. A passing number should still be documented with fiber ID, endpoints, wavelength, direction, test-set IDs, reference method, date, and technician. If the result fails, inspect and clean first, verify polarity and connector type, repeat the reference check, then use a <a href="https://bitcoinversus.tech/2026/07/11/fiber-training-visual-fault-locator-2/">VFL</a> for simple continuity or visible faults and an <a href="https://bitcoinversus.tech/2026/10/05/osfotc-003-otdr-field-testing-launch-receive-fibers-range-pulse-width-events-dead-zones-fault-location/">OTDR</a> when the location and character of loss events must be identified.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Field Workflow</h2><!-- /wp:heading -->
<!-- wp:list {"ordered":true} --><ol class="wp-block-list"><li>Confirm the fiber ID, endpoints, fiber type, connector type, and required test wavelength.</li><li>Verify the link is safe to test and disconnect active optics when the procedure requires it.</li><li>Inspect the reference-cord and link end faces.</li><li>Clean contaminated end faces and inspect again.</li><li>Power on the light source and power meter and allow any required stabilization time.</li><li>Select the correct wavelength on both instruments.</li><li>Connect the required reference-cord arrangement.</li><li>Store the reference value and document the reference method.</li><li>Connect the fiber under test without changing the fixed reference connection.</li><li>Measure loss in dB at each required wavelength and direction.</li><li>Compare measured loss with the acceptance limit.</li><li>Save the result with fiber ID, endpoints, direction, wavelength, instrument IDs, and date.</li><li>If the link fails, inspect/clean again, verify polarity, verify the reference, then isolate the fault with VFL or OTDR as appropriate.</li></ol><!-- /wp:list -->

<!-- wp:heading --><h2 class="wp-block-heading">Worked Example</h2><!-- /wp:heading -->
<!-- wp:list --><ul class="wp-block-list"><li><strong>Reference power:</strong> −1.5 dBm</li><li><strong>Measured far-end power:</strong> −3.4 dBm</li><li><strong>Measured loss:</strong> (−1.5) − (−3.4) = <strong>1.9 dB</strong></li><li><strong>Project maximum:</strong> 2.4 dB</li><li><strong>Result:</strong> PASS, with 0.5 dB remaining before the acceptance limit.</li><li><strong>Record:</strong> fiber ID, A/B endpoints, wavelength, direction, reference method, instrument IDs, date, and technician.</li></ul><!-- /wp:list -->

<!-- wp:heading --><h2 class="wp-block-heading">Fast Troubleshooting Order</h2><!-- /wp:heading -->
<!-- wp:list {"ordered":true} --><ol class="wp-block-list"><li>Inspect the end faces.</li><li>Clean and inspect again.</li><li>Confirm connector type and polarity.</li><li>Confirm wavelength and fiber type.</li><li>Recheck the stored reference with the reference cords.</li><li>Replace a suspect reference cord or adapter.</li><li>Repeat the loss measurement.</li><li>Use a VFL for continuity, bends, or nearby visible faults where appropriate.</li><li>Use an OTDR to locate reflective and non-reflective loss events.</li><li>Repair the physical cause and retest from the beginning of the acceptance workflow.</li></ol><!-- /wp:list -->

<!-- wp:heading --><h2 class="wp-block-heading">Exercises</h2><!-- /wp:heading -->
<!-- wp:list {"ordered":true} --><ol class="wp-block-list"><li>A reference is −3.0 dBm and the measured value is −5.2 dBm. Calculate insertion loss.</li><li>Explain why a dirty reference cord can corrupt every later test.</li><li>Name the information that should be saved with a passing loss measurement.</li><li>Explain when a VFL is more useful than an OTDR and when an OTDR is more useful than a VFL.</li><li>A link measures 2.8 dB against a 2.5 dB maximum. Write the first five troubleshooting actions in order.</li><li>Explain why the test wavelength must match the test plan and fiber application.</li></ol><!-- /wp:list -->

<!-- wp:heading --><h2 class="wp-block-heading">Knowledge Check + Answers</h2><!-- /wp:heading -->
<!-- wp:list {"ordered":true} --><ol class="wp-block-list"><li><strong>What should happen before mating or testing a fiber connector?</strong> Inspect it, clean it when necessary, and inspect again.</li><li><strong>What two instruments form the basic OLTS measurement?</strong> A stabilized optical light source and an optical power meter.</li><li><strong>How is insertion loss calculated from dBm readings?</strong> Reference power minus measured power, producing a positive loss value in dB for a normal lossy link.</li><li><strong>What is the answer to Exercise 1?</strong> (−3.0) − (−5.2) = <strong>2.2 dB</strong>.</li><li><strong>What should a technician do first after an unexpected high-loss result?</strong> Verify the measurement itself by inspecting/cleaning connections and checking the reference before assuming the installed fiber is damaged.</li><li><strong>Why record wavelength and direction?</strong> Because optical loss can differ by wavelength and direction, and repeatable acceptance evidence requires both.</li><li><strong>What does an OTDR add after a failed OLTS test?</strong> Distance-resolved evidence that can help locate connectors, splices, bends, breaks, and other loss or reflection events.</li></ol><!-- /wp:list -->

<!-- wp:heading --><h2 class="wp-block-heading">Elementary Conclusion</h2><!-- /wp:heading -->
<!-- wp:list --><ul class="wp-block-list"><li><strong>Inspect and clean first.</strong></li><li><strong>Reference the instruments correctly.</strong></li><li><strong>Measure at the required wavelength.</strong></li><li><strong>Compare the result with the approved loss limit.</strong></li><li><strong>Record enough evidence for another technician to repeat the test.</strong></li><li><strong>Troubleshoot the measurement path before blaming the installed fiber.</strong></li></ul><!-- /wp:list -->
